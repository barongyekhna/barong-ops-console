# 财务:每日利润表、广告盈亏、费用识别(殷乐乐的技能手册)

来源:liangdabiao/Amazon-Skills-Liang(MIT)—— amazon-fba-calculator、amazon-profit-analyzer、amazon-tariff-calculator
https://github.com/liangdabiao/Amazon-Skills-Liang/tree/main/skills
剥壳原则:只留口径与公式,去掉「先问用户选择题」的访谈壳;所有数以系统里的交易、广告报表和人手填的成本为准。

## 1. 利润表口径(每家店、每天、每个 SKU)
- 销售额 = 商品销售额 + 运费收入 + 促销折让(促销是负数)。
- 亚马逊费用 = 佣金(selling fees)+ FBA 配送费(fba fees)+ 其他交易费。
- 退款 = 退款行的合计(通常是负数;佣金会部分退回,已含在行里)。
- 其他费用 = 仓储费、长期仓储费、优惠券 / 秒杀费、订阅费、赔偿与调整、清算收入。
- 商品成本 = 当天售出件数 × 当时生效的(出厂价 + 头程)元 ÷ 当天人民币汇率。成本**只用人在财务页填的**;没填 = 缺成本。
- 广告费 = 广告报表当天的花费(不是后台的广告扣费行)。
- 利润 = 销售额 + 亚马逊费用 + 退款 + 其他费用 − 商品成本 − 广告费(费用在数据里是负数,注意符号)。

## 2. 不算利润的行(必须排除)
- 银行转账(Transfer / Übertrag):是提现,不是亏损。
- 跨账户结算(Verbindlichkeit):账户之间挪钱。
- 后台广告扣费(Cost of Advertising / Werbekosten):广告费按广告报表逐日算,这一行再扣就重复了。

## 3. 摊销与不完整
- 仓储费等月结费用摊到当月每一天,标「摊」。
- 缺成本的件数 > 0 → 这一天的利润标「不完整」,并列出缺哪些 SKU;不拿估算凑。
- 没有广告报表的日子 → 标「广告费待接入」,不估。
- 每次报数都说清:截至哪天、缺了什么。

## 4. 广告盈亏
- 广告带来的毛利 = 广告归因销售额 ×(这条线扣广告前的毛利率)。
- 广告盈亏 = 广告带来的毛利 − 广告花费。为负 = 在亏钱买量;交给殷素素处理,乐乐只报数。
- 注意:广告归因亏,不等于整条线亏——自然单可能撑着;所以「亏卖线」看的是扣完广告后整条线的利润。

## 5. 预警门槛(初始值,按经验库漂移)
- 亏卖线:某产品线近 14 天扣完广告的利润 < 0。
- 单件毛利底线:近 14 天单件毛利(扣广告前)< $4。
- 退款突增:近 14 天退款率 > 前 28 天的 2 倍,且至少 3 单。
- FBA 费变动:某 SKU 单件 FBA 费比前 30 天均值变动 > 10%(亚马逊调费或尺寸重新测量)。
- 缺成本:近 30 天有销量但没有成本的 SKU——账算不了,一店说一次。
