# 广告:漏斗、出价、否词(殷素素的技能手册)

## 1. 财务框架(每个出价决定的地基)
- 盈亏平衡 ACoS = 广告前利润率(售价 − 到岸成本 − 亚马逊费)÷ 售价。
- 目标 ACoS = 盈亏平衡 ACoS − 想留的利润率。新品前 4–8 周可以接受接近盈亏平衡;成熟期看 TACOS 不看 ACoS。
- 最高 CPC = 售价 × 目标 ACoS × 转化率;转化率不知道就用 10–15%;我们有销售与流量报表时用真实 unit_session_pct。
- 我们的现实:2026 夏两个月全成本毛利只有 1.9%,泵每件约 1 美元——盈亏平衡 ACoS 很低,所以「亏卖线」规则是硬门,不是建议。

## 2. 四活动漏斗(结构)
- 自动(发现词)→ 手动广泛(测词)→ 手动精准(收割赢家)→ ASIN 定向(打对手页面)。预算紧就先自动 + 精准。
- 起始出价:精准 = 亚马逊建议价与最高 CPC 取低;广泛 = 精准的 70–80%;自动 / 定向 = 精准的 50–70%。7 天且 20+ 点击后才调。
- 迁移:某词 2+ 单 → 升一级,并在源活动加为否词(防内部抢量);10+ 点击 0 单 → 源活动否精准;<20 点击 → 观察,不动。
- 跨店:三店同款同词,主场分配——谁转化最好谁主攻,其余店该词降价或否掉,别三家互相抬价。

## 3. 出价调整档(20+ 点击才有统计意义)
| 词的 ACoS | 动作 |
|---|---|
| > 200% | 砍 30–50% |
| 100–199% | 砍 20% |
| 目标 +10% ~ 99% | 砍 10–15% |
| 目标 ±10% | 不动 |
| 低于目标 | 加 10–20% |
| 10+ 点击 0 单 | 暂停 / 否词 |
我们的护栏:任何单次幅度不超过 ±25%,每店每日动作有上限,总闸一按全停。影子期只建议。

## 4. 否词
- 四档:核心转化词(保护并加价)/ 低频精准词(观察)/ 弱相关偶发转化(按 CPC vs 转化价值评估)/ 纯浪费(立刻否)。
- 我们的第五档「需求储备」:带加热意图的词(heat / hot water / warm / heiz / warmwasser)在泵上不否——那是热水棒和套装的需求,记进储备。
- 否精准 vs 否短语:单个浪费词用否精准;一类无关搜索用否短语(例:free 否短语挡掉 free shipping 等全部)。
- 活动级(整条产品线都无关的词)vs 广告组级(匹配类型之间微调:精准组对已单独投的核心词加否短语,广泛组保持开放)。
- 种子否词三类:跨活动(精准词加进广泛 / 自动)、不相关(错材质 / 错产品 / 错意图)、通用浪费(free、cheap、used、diy、review、how to)。
- 节奏:每周审一次搜索词报表;报表有 72 小时延迟;季节性否词到期要移除;否之前算净节省 = 浪费花费 − 可能损失的转化价值。

## 5. 全漏斗与生命周期
- SP 漏斗底(意图明确,转化最高);SB 漏斗中(品牌旗舰店);SD 全漏斗(再营销 + 打对手买家)。我们现在只做 SP,SB / SD 等品牌备案和预算。
- 生命周期:新品容忍高 ACoS 换曝光;成长期压到目标 ACoS;成熟期盯 TACOS。广告是排名助推器,不是销售渠道——长线把 TACOS 压下去。
- 预算按边际收益分:核心词精准 / 短语边际收益最高;对手防御用 SD 定向。

## 6. 分时与旺季
- 亚马逊本身不支持分时出价,要靠预算规则或第三方;晚 7–11 点是购物高峰,深夜最低;家居厨房晚间 + 周末高峰。等 Ads API 预算规则接上再做,影子期不做。
- 旺季:促销前 1–2 周逐步加预算积累质量分;旺季预算 2–3 倍并集中在高转化词;促销结束后逐步降,别让转化率下滑把 ACoS 顶上去。竞价上涨、ACoS 短期升高是正常的。
- 季节倒计时:泵 6/1–7/19 预热、7/20–8/20 高峰;热水棒 10/6–11/15 预热、11/16–2/15 高峰;套装 10 月起。倒计时 45 天提醒。

## 7. 开口时怎么用
- 每条建议说清:做什么、为什么(带数字和数据截至日)、预计几天后看到什么(7/14/28 天)、护栏在哪。
- 只在自己拿到的数据上说话;没数据就说没数据。
