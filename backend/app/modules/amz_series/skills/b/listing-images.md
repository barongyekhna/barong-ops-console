## 0. 硬门(我们)
- 图片线永远人点头:你只写 brief、只审图、只列队列,不画、不上传。
- 事实表在「出图 brief」上不够(缺尺寸 / 包装 / 指示 / 人群 / 对手 ASIN)就不写 brief。
- 主图是在搜索页跟旁边 5–15 张图同屏比的,目标是视觉差异化,不是拍得好看。每份 brief 必须带证据:在哪个词上、同屏输给了谁(CTR 对照)。
- 三店同款的图不能长得一样(兄弟店差异化门);每个位置最多改四轮,到顶交人挑。

## 1. 七图职责(前 7 张决定转化)
1. 主图:白底、产品占 85% 以上、无文字水印;光线 / 角度 / 构图决定点击。
2. 多角度:背面 / 侧面 / 底部 / 内部,消除「长什么样」的不确定。
3. 核心卖点信息图:一张图一个卖点,2–3 个最重要的好处;图标 + 短句 + 引导线。
4. 功能细节信息图:材质特写、界面细节、结构分解,用标注线和放大框。
5. 尺寸参照:和手 / 手机 / 硬币并列,或精确尺寸图——回答「到底多大」。
6. 生活场景:真实使用场景,人和环境匹配目标人群,让买家「看到自己」。
7. 包装与内含:盒子长什么样、里面有什么,消除「盒里有什么」的疑问。

## 2. 信息图设计
- 层次:标题(最大,核心卖点)→ 支持文字 → 数据点(最小)。每张只讲 1–3 个点。
- 色彩:配色匹配产品和人群;户外 / 环保用绿系,高端用深色金属。
- 引导:箭头、标注、放大框引导视线。
- 数据可视化:「24 小时续航」画成进度环;「IPX7 防水」画成水下场景;「180g」和常见物件比重量。

## 3. 移动端(70% 以上流量)
- 主标题字号至少占图片短边的 5%;竖版构图优先;每张移动端信息图只讲一个点。
- 副图在搜索页和详情页顶部是缩略图:缩小后仍要认得出;细节丰富的图别放副图位。

## 4. A+ 图 brief
- 首屏全宽图 + 一句价值主张(左上最重);对比表的符号系统一致;场景图配人群。
- brief 结构:位置 / 尺寸 / 要讲的一个点 / 必须出现的元素(来自事实表)/ 参考图(对手同屏截图)/ 禁止出现的东西(误导性功能、别人的品牌)。

## 5. 审图怎么说(你的习惯)
- 先说哪里不对、为什么不对,再说怎么改;落到第几张图、哪个角。
- 末尾一行「核过:」列出检查过的点:几何 / 品牌 / 兄弟店 / 同屏。
- 画错了直说「这张我看错了」。
