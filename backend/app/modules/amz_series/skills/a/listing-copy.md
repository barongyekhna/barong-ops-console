# Listing 文案:标题、五点、描述、后台词、A+(殷笑笑的技能手册)

来源:liangdabiao/Amazon-Skills-Liang(MIT)—— amazon-listing-optimization、amazon-backend-keywords、amazon-search-optimization、amazon-a-plus-content、amazon-return-reduction
https://github.com/liangdabiao/Amazon-Skills-Liang/tree/main/skills
剥壳原则:只留规则和数字,去掉访谈壳与多平台泛化;我们的加法用「我们:」标出。

## 0. 硬门(我们)
- 事实表在这个用途上「不够」就不写——缺什么先要什么。写出来的每一句都要能在事实表里找到依据。
- 三店同款(01us / 03us / 04us 的泵)文案不能长得一样:同一个词各店接法要不同,这是占位策略的硬线。
- 「它不是什么」必须进文案(五点或描述):不加热、不能接水管——误解堵在页面上,差评就少一半。

## 1. 字符上限与分配
- 标题 ≤ 200 字符;五点每条 ≤ 500;描述 ≤ 2000;后台搜索词 ≤ 250 字节。
- 关键词分层:主词(搜索量最高)→ 标题靠前;次词 → 五点每条一个;长尾 → 描述;剩下的 → 后台词。
- 我们的词从哪来:广告搜索词报表里成交过的词 + SQP 里我们有份额的词;不用外部抓取。

## 2. 标题
- 结构:品牌 + 主词 + 关键属性 1 + 关键属性 2 + 次词 + 差异点。主词紧跟品牌之后;前 80 字符是手机上能看到的全部。
- 不全大写(品牌除外);不写 best / #1 / top rated;和搜索相关的尺寸 / 颜色 / 数量要写进去。
- 位置权重:标题 > 五点 > 后台词;标题里越靠前权重越高。

## 3. 五点
- 格式:「大写利益点 — 自然嵌入关键词的说明」。
- 五点 1 主特点 + 主词;2 关键场景 + 次词;3 材质 / 质量 + 信任信号;4 包装内含 / 兼容;5 保证 / 差异化。每条至少一个目标词。
- 我们:第 3 或第 4 条放「它不是什么」和指示灯 / 屏幕的含义(红灯充电、绿灯充满、屏幕是水温 °F)。

## 4. 描述
- 开场痛点 → 特点到利益(展开五点,不逐字重复)→ 行动号召 + 内含。嵌入标题五点没用到的词。换行分段。

## 5. 后台搜索词(250 字节)
- 只放页面上没有的词;标题五点已有的词不加权重、白占字节。
- 词干去重(running 覆盖 run / runner);语义去重留搜索量高的;空格分隔不用逗号。
- 放高频拼写错误(只选真高频的)、同义词和地区叫法(portable charger vs power bank);美国站留 30–50 字节给核心卖点的西班牙语。
- 禁:别人的品牌名(会被压制)、best / free shipping 这类受限声明、主观词。

## 6. 8 维审计记分卡(诊断用,满分 100)
标题 15 · 五点 15 · 图片 15 · A+ 10 · 描述 10 · 定价 10 · 评论 15 · SEO 覆盖 10。
- 覆盖率:目标词在标题 / 五点 / 描述里的命中比例;≥90% 优、70–89% 有小缺口、<70% 要改。
- 我们:诊断结论要落到「哪一句改成什么」,附改好的原文带引号,让人能直接复制。

## 7. 搜索算法怎么看页面(A9 / COSMO)
- 先按相关性过滤(标题 / 五点 / 后台与搜索词匹配),再按近期销售速度、转化率、点击率排;评分、评论数、退货率是满意度信号。
- COSMO 看意图和语义(「无线耳机」≈「蓝牙耳机」),堆词没用,把使用场景和人群写清楚更有用。
- 索引验证:搜「ASIN + 关键词」能出来就是被索引了;改标题 / 后台词后要几小时到几天才重新索引。

## 8. A+
- 模块顺序:抓注意(首屏全宽图 + 一句价值主张,重点放左上)→ 建信任(品牌故事 / 技术 / 认证)→ 配需求(场景 + 使用指南)→ 对比表(选能突出我们差异的维度,符号一致,保持客观)。
- 每个模块「特点 → 优势 → 利益」;移动优先:字号、每模块信息密度、点击区域。
- 我们:A+ 的图 brief 交给殷熊,文案在这里。

## 9. 退货与文案
- 很多退货来自页面不准:照片过度美化、尺寸只给数字没有参照、功能夸大、材质模糊、兼容性没写。
- 原则:如实描述、适当降低预期,让买家「超出预期」。退货率阈值一般 3–10%,超了影响排名和促销资格。

## 10. 语言
- 美国站英文,德国站德文;文案和诊断都用目标市场语言。跟老板汇报用中文。
