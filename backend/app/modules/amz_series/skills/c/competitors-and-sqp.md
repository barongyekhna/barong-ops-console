## 0. 硬门(我们)
- 只报变化,不报数字堆;事实、判断、建议分开说。
- 绝不建议刷单、激励评论、返现换评——只走「请求评论」和 Vine。
- 对手动作转给对的人:断货 → 素素加广告位;换主图 → 殷熊过同屏门;降价 / coupon → 先看价格再定。

## 1. SQP(搜索词表现)怎么读
- 四个份额都是「我们 ÷ 全市场」:曝光份额、点击份额、加购份额、购买份额。
- 点击份额 > 购买份额 = 人点进来了没买 = 详情页在漏(价格 / 图 / 五点 / 评论 / 配送)。差距越大越急。
- 购买份额 > 点击份额 = 转化效率高,可以加广告拿更多点击。
- 曝光份额低 = 词没接住(标题 / 后台词 / 广告位)。
- 曝光在、点击掉 = 搜索页同屏输了(主图 / 标题前半句 / 价格 / 评分)。
- 数据有约 72 小时延迟;只显示前三名品牌的份额;跨周比要看全市场曝光量有没有一起变。

## 2. SFR(搜索频率排名)
- 数字越小搜索越多;价值在趋势:从 5000 升到 2000 = 需求在升温。
- 相对排名不是绝对量:Prime Day 那周整体激增,SFR 变化不代表真实兴趣变化。

## 3. 竞品对比框架
- Listing 质量:标题关键词覆盖、五点信息密度、图片、A+ 完整性。
- 关键词差距:对手排名而我们没有的高搜索词。
- 价格-评论矩阵:价格 × 评论数 / 评分两轴摆位,找价格带空白;识别价格战(价格接近成本)。
- 广告可见度:对手在核心词上赞助位出现频率 → 推断预算;广告主少的词 = 便宜流量。
- 我们:对手名单每条产品线一份;每天一张快照(价格 / coupon / 库存 / 主图哈希 / 评论数 / 评分 / BSR),只报变化。头部对手评论 800–3000 条 4.5 星 vs 我们 25 条 4.1 星,这个差距只能靠时间和合规催评,别幻想一周追平。

## 4. 评论分析
- 星级分层:1–2 星找投诉主题,4–5 星找赞扬点(用作文案和广告话术)。
- 投诉排序:频率 × 严重度(退货、A-to-Z)× 分布(个别 vs 系统性)。高频系统性最优先。
- 隐性需求:「要是有个收纳袋就好了」这类话是改进方向。
- 对手评论:他们被反复夸的 = 我们的基准线;被反复骂的 = 我们的差异化机会。
- 改进矩阵:影响力 × 难度;高影响低难度先做。
- 我们:归成三簇——产品缺陷 / 预期落差(页面没讲清)/ 物流;预期落差归笑笑,缺陷归事实表和工厂。<50 条评论统计意义弱,别下重结论。

## 5. 评论合规
- 「请求评论」:发货后 5–30 天窗口,一单一次,转化 2–5%,完全合规、可自动化——这是基础。
- 盒内插卡:可以感谢、说明、客服联系方式、中立邀请(「满意的话欢迎分享体验」);不能折扣换评、不能只引导好评。
- Vine:品牌备案卖家;上架后 30–60 天是窗口;4–8 周见效;每个 ASIN 收费;评论不可控,产品有问题会被暴露;0→10 条评论转化率能涨 50–150%。
- 评分掉 0.1 星,转化率可能掉 5–10%;评论里的词也参与索引。

## 6. 季节日历
- Prime Day 7 月、返校季 7–8 月、黑五网一 11 月、Q4 假日季 10–12 月;情人节 2 月、母亲节 5 月。
- Q4 海运:生产 2–4 周 + 海运 4–6 周 + 旺季入仓 1–3 周 → 8 月底 / 9 月初前下单。
- 促销:秒杀 4–12 小时要 20% 以上折扣;当日特惠;Prime 独享折扣门槛低可长期;优惠券灵活。申请开放要立刻提交。
- 对手季节动作:上次折扣深度、库存、广告位、有没有趁旺季推新品。对手库存低 → 抓断货窗口;对手推新 → 用老品促销和广告防守。
- 我们:老板被压货伤过——「宁可积压」不是我们的规矩,我们的规矩是库存天数 ≥ 45 天进旺季、断货前 45 天提醒、总闸随时按。促销后有「悬崖」,排名要几周恢复,提前说。
