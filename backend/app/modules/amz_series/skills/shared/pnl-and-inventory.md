## 1. 利润瀑布(每个 ASIN 都要能算出来)
收入 → 减 COGS(出厂 + 头程)→ 减 FBA 配送费 → 减推荐费(约 15%)→ 减广告 → 减退货损失(退货运费 + 不可售)→ 减隐藏费(长期仓储、移除、优惠券成本)→ 净利。
- 盈亏点三样:最低售价、最高 ACoS、最高退货率。
- 我们:成本来自事实表(出厂 + 头程手填,不连制造系统);汇率 1 美元 ≈ 7.2 元,1 欧元 ≈ 1.08 美元(A1 汇率作业上线前的固定值)。2026 夏两个月全成本毛利 1.9%,这是所有建议的背景。

## 2. FBA 尺寸层级(2024)
| 层级 | 最大重量 | 最大尺寸 |
|---|---|---|
| 小型标准 | 1 磅 | 15"×12"×0.75" |
| 大型标准 | 20 磅 | 18"×14"×8" |
| 小型大件 | 70 磅 | 60"×30" |
| 中型大件 | 150 磅 | 长 + 周长 ≤ 108" |
| 大型大件 | 150 磅 | 长 + 周长 ≤ 165" |
事实表要有 dimensions_cm 和 weight_g 才能定层级;月度仓储费旺季不同;271 天以上有长期仓储费。

## 3. 到岸成本
- CIF = FOB 货值 + 国际运费 + 保险;关税 = CIF × 基础税率 + CIF × 301 税率(中国→美国);VAT 基数 = CIF + 关税;到岸 = CIF + 关税 + VAT + 清关(约 $150)+ 港口(约 $50)+ 内陆运输。
- HS 前 4 位定 301 税率:电源 / 变压器 8504 25%;通讯 8517 25%;家具 9403 25%;玩具 9503 25%;服装 7.5%。基础税率:电子电气 85 章美国 0%、欧盟 2%;塑料 39 章 6.5%。
- 我们:泵、热水棒、手电、磨甲器各自的 HS 与税率写进事实表的 cost 备注,损益表门用它。

## 4. 库存
- 补货点 = 日均销量 ×(采购交期 + 运输 + 入仓 + 安全缓冲)。日均按 30–60 天滚动;海运 30–45 天、空运 5–10 天;入仓 5–10 工作日,Q4 2–3 周;缓冲 = 总周期的 20–30%。
- 安全库存 = 服务水平因子 × 需求标准差 × √补货周期;服务水平 95–98%。
- IPI 0–1000,四维:积压、周转、滞留、缺陷;< 500 会被限仓,到下季度评估前恢复不了。
- 季节:Q1–Q2 清积压提 IPI;Q4 货 8–9 月海运到。
- 我们:上架前门要求库存 ≥ 45 天;断货是 D 的告警;老板被压货伤过,「多备」要给出天数和钱,不说空话。

## 5. 退货
- 根因:页面不准(照片美化、尺寸无参照、功能夸大、材质模糊、兼容没写)、包装(到达损坏)、尺码。
- 阈值一般 3–10%;超了影响排名、促销资格、账号健康。改页面 2–4 周见效,改产品 2–3 个月。

## 6. 变体
- 同父体共享评论、聚合流量、关键词权重集中;新子体能继承评论。
- 合规:只能是同一产品的颜色 / 尺寸 / 数量变体;功能不同的不能合并,违规会被强拆。
- 最佳子体由销售速度、转化率、库存决定,搜索页展示它。
- 我们:三店同款分属三家公司,不能跨店做变体;同店内颜色变体可以;套装是新品走推新流程,不是变体。
