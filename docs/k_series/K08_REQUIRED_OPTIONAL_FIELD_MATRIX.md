# K08 Required Optional Field Matrix

Status: K08A required/optional matrix draft, pending owner review.

Date: 2026-06-12.

## 1. Required-level definitions

- `required_at_creation`: must be present when a Product Knowledge record is created.
- `required_before_keyword_research`: must be present before K15/K19 keyword research or keyword management can run.
- `required_before_category`: must be present before category suggestion or category approval work.
- `required_before_page_blueprint`: must be present before a future page-structure blueprint can be generated.
- `required_before_content_generation`: must be present before AI/template content generation can use the product.
- `required_before_media_work`: must be present before image selection, visual profile work, or future media generation can proceed.
- `required_before_woo_draft`: must be present before a future WooCommerce draft can be generated.
- `required_before_publish_review`: must be present before the product can enter final publish review.
- `optional`: may be absent without blocking the stage.
- `conditional`: required only when the product, market, category, variant, shipping, compliance, or workflow context requires it.
- `system_generated`: generated by K/system behavior, not by operator input or AI fact generation.

K08A only defines these levels. It does not implement validation code.

## 2. Creation minimum fields

Minimum creation fields:

- `product_key`
- `source_system`
- `raw_input_text` or `product_name_en`
- `raw_input_language`
- `workspace_key`
- `business_context`
- `scope_mode`
- `product_status`
- `review_status`
- `canonical_language`

Creation notes:

- `raw_input_text` is preferred because it preserves original language and context.
- `source_system` is required at creation and may default to `manual`; it marks manual, imported, future API, or future Barong intake origin and does not make Google Sheets a long-term source of truth.
- If `raw_input_text` exists, `raw_input_language` must preserve the original language code or an owner-approved unknown value.
- If creation uses only `product_name_en`, `raw_input_language` may default to `en`.
- `workspace_key`, `business_context`, and `scope_mode` are K Scope Shim values during adapter-pending.
- `canonical_language` defaults to `en`.
- K10/K13 depend on `raw_input_language` for translation and multilingual checks.
- Product creation does not mean the product is ready for downstream use.

## 3. Keyword research minimum fields

Minimum fields before keyword research:

- `product_key`
- `product_name_en`
- `product_type` or `category_hint`
- `primary_use_case_en` or `short_description_en`
- `target_market` or approved default market
- `review_status` not blocked

Keyword readiness notes:

- `target_market` is a readiness/request context, not a required products-table column in K08A.
- Product creation must not be blocked because `target_market` is missing.
- Keyword research must be blocked if no `target_market` or approved default market can be resolved.
- Target market resolution priority:
  1. Explicit keyword research request payload.
  2. Product/workspace default market setting.
  3. Owner-approved fallback default.
  4. Future `k_product_knowledge_research_runs.target_market`.
- K09 uses `target_market` or `display_market` for unit display decisions, but K08A does not implement runtime storage.
- AI/provider keyword output remains candidate data until reviewed.
- K15 must not call live SERP/OpenAI/Claude unless future tasks and owner approval allow it.

## 4. WooCommerce draft minimum fields

Minimum fields before a future WooCommerce draft:

- `product_key`
- `product_name_en`
- `sku`
- `product_type`
- `regular_price` or price policy placeholder
- `price_currency`
- `stock_status`
- `short_description_en`
- `long_description_en` or page content source placeholder
- dimensions / weight if relevant
- `category_path` or approved category
- image readiness status
- risk review not blocked

Woo draft notes:

- AI must not invent price, SKU, dimensions, weight, stock, category, claims, certifications, or media selections.
- A placeholder is acceptable only when it is explicit and reviewed as a placeholder.
- `category_path` or approved category is required before Woo draft.
- `merchant_product_type` is required before Woo draft only when Woo/catalog draft requires merchant category mapping; otherwise it is recommended before feed/catalog usage.
- `google_product_category` is required when the target channel includes Google Merchant/Product Feed, not for every basic Woo draft.
- K07/K08 must not make `google_product_category` an early hard requirement for all products.
- K08A does not call WooCommerce and does not create WooCommerce drafts.

## 5. Publish-review minimum fields

Minimum conditions before publish review:

- canonical product facts reviewed
- price reviewed
- category reviewed
- claims reviewed
- risk terms reviewed
- media reviewed
- SEO reviewed
- operation/review records present

Publish-review notes:

- Future formal approval gates wait for C12.
- Future operation log display waits for K21/C17 and must not modify the `operation_logs` table structure.
- K08A only defines the field expectations for this stage.
