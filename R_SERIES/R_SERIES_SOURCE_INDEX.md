## 2. 结论与来源映射

| 重要结论 | 主要依据 |
|---|---|
| Amazon 选品应优先对齐 Amazon 官方 listing、定价、履约、广告和品牌工具框架 | A00 |
| Amazon 选品应从 niche/需求簇出发，而不是单 SKU 猜测 | A01 |
| BSR 是销售排名信号，不是机会本身，也不等同产品质量或搜索排名 | A03 |
| Best Sellers、Movers & Shakers、New Releases 可用于发现线索，但必须与长期趋势和利润交叉验证 | A02、A03、T02 |
| FBA 适配必须检查重量、尺寸、仓储、退货、移除等费用 | A04、A06 |
| Amazon 新品冷启动必须估算 CPC 与广告后利润 | A05 |
| 受限、危险品、认证、IP、专利风险应先于销量判断 | A02、A04、G02 |
| 独立站产品必须验证搜索意图、内容机会、广告经济性、信任门槛、GMC 合规和站点运营适配 | G01、G02、G03、S01、S03、W01 |
| Google Merchant Center 需要商品数据和落地页一致，虚假或不透明信息会带来账号风险 | G01、G02 |
| SEO 选品不能只看搜索量，还要看意图、难度、流量潜力和商业潜力 | S02、S03 |
| Reddit/YouTube/TikTok/Pinterest 可用于洞察用户语言、痛点和视觉卖点，但不能单独证明需求 | S01、S03、S04 |
| 工厂型卖家的优势应转化为改良、定制、质检、案例、规格和小批量验证 | A01、S01、Barong 已知背景 |
| R 系列应先建立评分、淘汰和下游交接机制，再考虑更复杂自动化 | 全部来源交叉结论 |

## 3. 可信度分层

高可信来源：

1. Amazon 官方：用于 Amazon 需求、BSR、FBA、广告、机会工具、榜单逻辑。
2. Google 官方：用于 Merchant Center、Ads、Search structured data、政策风险。

中高可信来源：

1. Shopify：用于 DTC/独立站产品研究框架。
2. Ahrefs、Semrush：用于 SEO、关键词、搜索意图和内容机会。
3. WooCommerce：用于产品类型、变体、属性、库存、尺寸重量等独立站运营适配。
4. Helium 10、Jungle Scout、Keepa：用于 Amazon 工具型选品维度。

中可信来源：

1. SellerSprite：适合中文卖家实操，但具体数据应以账号实测和多工具交叉为准。
2. Reddit、YouTube、TikTok、Pinterest、Quora：只用于用户语言、痛点、趋势和视觉内容灵感。

## 4. 使用注意

1. 工具估算不等于真实后台数据。
2. 榜单热度不等于进入机会。
3. 搜索量不等于购买转化。
4. 社媒热度不等于长期需求。
5. 低竞争不一定是机会，可能是合规、专利、退货、供应或利润问题。
6. 任何涉及认证、危险品、IP、专利、医疗/健康功效、儿童用品的候选，都必须人工复核。
7. R 系列输出应该记录证据链接、截图时间、数据来源、评分人和复查条件。
