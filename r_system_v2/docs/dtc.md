# 独立站 DTC 选品准则（references/dtc.md）

平台经济学:**需求是你造的 / 你抢的**。独立站没有现成搜索框等你,流量两种来源:
**付费广告**(你买流量)和 **SEO 自然搜索**(你排上去)。两者经济学不同,挑的产品也不同。
所以独立站轨分**两条子路 + 两套评分卡**,共享下方的 DTC 红线,最后汇入同一个三层 AI 漏斗。

---

## 子路 A · 广告品(付费流量驱动)

生死线:**CAC 天花板 = 客单价(AOV) × 毛利率**。获客成本高于此,每单都亏。

- **毛利 ≥ 60%(gross)**;60–70 gross / 10–20 net 是存活区;<50% gross 直接剔除;加价 3–5×。
- **价格冲动区 $25–$65**;bundle/加购提 AOV;利润藏在售后追加销售。
- **3 秒视觉钩子(一票否决)**:刷到广告 3 秒内能 get —— 独特设计 / 可短视频演示的具体问题 / 强情绪或身份认同。平庸、无法 demo = 剔除。
- **复购 / bundle / 订阅** 潜力,摊薄 CAC。
- **需求验证**:Meta/TikTok Ad Library **有人持续投**(尤其投放时长 `ad_run_days` 长)= 已验证。
- **反商品化**:已被亚马逊价格战的品别上(用户会比价跑掉)。
- **履约**:轻、不易碎、低退货($45 品 +$14 运费 +10% 退货 = 结构性烂品)。

**KEEP 画像**:毛利 60%+、$25–$65、3 秒钩子可 demo、解决具体问题或身份认同、有复购/bundle、
Ad Library 有人持续投、亚马逊上没被打成红海、轻且低退货。

---

## 子路 B · SEO 品(自然搜索驱动)

**和广告品挑的产品几乎相反。** SEO 要 3–6 个月起效,所以挑的是**常青、被搜索、可内容承接**的品。

- **可搜索的问题**:产品要对应一个人们会去 Google 搜的问题/需求,有**买家意图关键词**
  ("best X""X for Y""buy X""问题+解决"),不是纯信息词。
- **有搜索量**:Google Ads Keyword Planner 取量,够大值得做、不至于被巨头锁死。
- **SERP 弱点(核心机会信号,Serper 抓)**:目标关键词的 Google 页一**好不好打** ——
  被论坛/Reddit/Quora/维基/薄内容占据 = 弱 = 机会;被有权威深内容的强 DTC 品牌锁死 = 跳过。
- **常青**:Google Trends 上升/稳定,**非 viral 尖峰**(SEO 等不起短命需求)。
- **可内容承接**:能围绕它做内容(教程/对比/选购指南)排上去再导流到产品。
- **毛利要求放松**(关键差异):**SEO 边际 CAC 趋近于零**(排上去后流量近乎免费),
  所以广告漏斗会因"毛利不够付广告"毙掉的品,SEO 漏斗可能恰恰能做 —— 更高考虑度、更低毛利、更长决策的品。
  毛利下限可降到 ~40%(仍要扛履约+退货),不强求 60%。

**KEEP 画像**:对应一个被搜索的具体问题、有买家意图词且有量、Google 页一弱(论坛/薄内容占位)、
常青上升、能做内容承接、毛利 ≥40% 且履约友好。

---

## ★ Keepa × Serper 交叉(SEO 选品的杀手锏)

> **Amazon BSR 强(需求已验证)+ Google SERP 弱(没有强 DTC 内容在排)= 独立站 SEO 理想品。**

用 Keepa 证"有人买"(真实需求),用 Serper 证"Google 上没人好好做这个词"(能排进去)。
两者同时满足的品,是独立站能靠免费自然流量吃下、且**未被广告党和 SEO 党同时盯上**的缝。
这类同时也是最强的 `dtc_migration_candidate`(亚马逊已验证 → 独立站 SEO 承接)。

---

## DTC 通用红线（两条子路都适用,命中即剔除）
- 广告品 gross<50% / SEO 品 gross<40%(扣履约退货后)
- 重 / 易碎 / 高运费 / 高退货,吃光毛利
- 广告品:无法 3 秒 demo;SEO 品:无可搜索问题 / 无买家意图词
- 已被亚马逊价格战商品化(用户会比价跑掉)
- 液体 / 易碎重货 / 侵权 / 强制认证(见 shared.md;锂电不是红线)

> Opus 终筛对 DTC 保留品额外产出:广告品→广告钩子假设(前3秒)+bundle 结构+落地页卖点;
> SEO 品→目标关键词簇 + 内容角度(要写什么排上去)+ 落地页转化点。
