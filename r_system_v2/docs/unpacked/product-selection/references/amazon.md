# 亚马逊 FBA 选品准则（references/amazon.md）

平台经济学:**需求是现成的**。人已经在亚马逊搜索框里打字。你不需要"造需求",
你需要抢到自然位、突破评论壁垒、在一个对手没锁死的细分里用更好的 listing/产品胜出。
**赢家 = 稳定需求 + 可攻竞争 + 扛得住费用的利润。**

---

## 一、硬指标与阈值（2026）

### 价格带
- **甜区 $25–$70**。低于 $20:FBA 费用吃掉大部分利润;高于 $80:决策变慢、退货率上升、回本变长。
- 小卖家优先 $25–$50,资金周转快、试错便宜。

### 利润
- **净利目标 25–30%**(扣完 2026 全部费用:referral + FBA + 仓储 + PPC 后)。
- **3× 规则**:售价 ≥ 3 × 到岸成本(产品 + 头程),作为进货前的快速 sanity check。
- **净利 < 15% 直接剔除** —— 这种品扛不住任何价格战/费用上涨/退货,一压就亏。
- 注意 2026 新增/易被低估的费用:入仓配置费、低库存费、退货处理费、181天以上陈货附加费、AWD 仓储附加费。工具给的费用估算常低估 20–40%,按悲观值算。

### 需求
- **BSR**:主类目 BSR **< ~50,000** = 稳定有量。但**看 90 天 BSR 走势,不看单点快照**。
- 月销参考 **200+ 件**(理想 1,000+),且跨多个卖家都有量 = 需求真实。
- 关键词月搜索量**甜区 1,000–10,000**:低于 1,000 盘子太小撑不起库存投入;高于 10,000 通常已有品牌级对手砸广告。

### 竞争(小卖家的"中等门槛"区 —— 最重要)
- **页一 top3 评论数 < ~300**:评论壁垒可破。
- **review velocity 比绝对数更重要**:50 评论但每月 +10 的 listing,比 400 评论每月 +2 的更难打
  (前者在快速积累优势)。慢速度类目 = 新人有上页一的现实路径。
- **卖家数 3–15 个 FBA 卖家**:1 个通常是私牌锁定;50 个是价格血战(race to the bottom),避开。
- **单一品牌份额 < ~30%**:有品牌锁了一半以上份额 = 你打不穿,避开。
- **New Product Ratio(页一中 <12 月新品占比)高 = 类目没固化、可进**;极低 = 老品牌锁死,避开。

### 价格地板趋势(Keepa 的杀手锏)
- **12 个月价格地板 持平或上行 = 健康**(大家靠价值竞争)。
- **持续下滑 = 商品化 / 价格战,直接剔除** —— 这是新进入者最大的陷阱:当前营收快照好看,但毛利在融化。

### 趋势 / 反 viral
- 主关键词 12 个月趋势 **持平或增长**。
- 3 个月前突然起量、此前无历史 = **viral 待证伪**,默认剔除,别赌。

### 履约 / 类目红线
- **轻(< 2 lb)、不易碎、体积小**(省 FBA 费 + 仓储费 + 降破损)。
- 退货率高的类目按基线计入利润模型:电子 20–25%、带尺码服装高。**复杂电子、易碎、尺码服装慎做**。
- 避开:锂电、需冗长审批的 restricted 类目、IP/侵权高发(频繁 IP alert)的品。

### 差异化钩子(必须有)
- 页一 listing 有明显弱点你能改:差评集中点(如"用两周螺丝松了")、烂主图、弱 bullet、缺变体。
- **没有可改进的弱点 = 没有切入点 = 剔除**。改进必须是"活儿"能做的(设计/包装/listing/bundle),
  不是要砸大钱/上认证的(那是资本门槛)。

## 二、Keepa 字段 → 判断映射(给富化阶段用)

| 判断 | Keepa 数据 |
|---|---|
| 需求稳定性 / viral 识别 | `salesRanks` / BSR 历史(12个月) |
| 价格战识别 | 价格历史的**地板线** 12 个月走势 |
| 竞争强度 | `offers` / 卖家数、Buy Box 卖家历史 |
| 评论壁垒 | RATING / COUNT_REVIEWS 历史 + review velocity(增速) |
| 利润测算 | 当前价 + 类目 referral% + FBA 费(尺寸/重量) |
| 季节性 | BSR/价格 12 个月周期形态 |

> `offers` 参数耗 token 多,**只对规则预筛通过的候选拉 offers**,别全库拉。

## 三、KILL LIST（命中任一即剔除）

- 净利 < 15% 或加价 < 3×
- 价格地板 12 个月持续下滑(价格战)
- 卖家数 > 15 且无差异化空间(红海)
- 单一品牌份额 > ~50%(类目锁死)
- 页一 top3 评论 > ~500 且增速快(壁垒太高)
- viral 待证伪(无 12 月历史的暴涨)
- 锂电 / restricted / 高 IP 风险 / 易碎重货 / 尺码服装(除非有把握)
- 改进点需要大额资本或强制认证(= 资本门槛,小卖家做不起)

## 四、KEEP 画像（理想亚马逊品）
轻、$25–$50、净利 25%+、BSR 稳定在万级内、卖家 3–15、页一评论数低且增速慢、
价格地板 12 个月持稳、有一个"靠活儿就能补"的明显改进点、常青非季节。
